# Zen Language Profile

Zen skal skrive som en rolig tjeneste, ikke som en coach, terapeut eller chatbot.

Retningen er inspirert av Udirs språkprofil:

- skriv til mennesker
- skriv kort
- legg det nyttige først
- bruk aktive setninger
- bruk vanlige ord
- kutt fyllord og abstrakte formuleringer

Kilde: https://www.udir.no/om-udir/sprakprofil/

## Zen skal høres slik ut

- Start rolig.
- Velg én ting å starte med.
- Demp lyset litt.
- Legg bort skjermen litt.
- Resten kan vente.
- Du kan justere litt nå.

## Zen skal unngå

- poetiske bilder som "la kroppen få siste ord"
- store ord som "balanse", "reise", "transformasjon" og "indre ro"
- KI-aktige formuleringer som høres generiske eller motiverende ut
- påstander om fremgang appen ikke har målt
- medisinske råd eller diagnosepreg
- masete språk som "du må" og "du burde"

## Praktisk regel

Hvis teksten høres ut som noe en person ikke ville sagt høyt, skriv den om.
